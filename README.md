# 🎓 Tutur – Dashboard Pembelajaran Bahasa Daerah

Tutur adalah konsep desain antarmuka platform pembelajaran bahasa daerah yang dibuat untuk memberikan pengalaman belajar yang modern, nyaman, dan mudah digunakan.

Desain ini berfokus pada tampilan **responsive**, sehingga pengguna dapat mengakses dashboard melalui perangkat desktop maupun mobile.

## 📌 Tampilan Desain

### 1. Dashboard Desktop

![Dashboard Desktop](tutur-dasbor-desktop.png)

Dashboard desktop memiliki tampilan yang lebih luas dengan navigasi sidebar di sebelah kiri.

**Fitur tampilan:**
- Sidebar navigasi Beranda, Kelas Saya, Kelas Langsung, dan Profil.
- Informasi aktivitas belajar pengguna.
- Statistik jumlah hari belajar, pelajaran selesai, dan waktu belajar.
- Kartu untuk melanjutkan pelajaran.
- Informasi jadwal kelas langsung berikutnya.

### 2. Dashboard Mobile

![Dashboard Mobile](tutur-dasbor-mobile.png)

Dashboard mobile dirancang dengan layout yang lebih sederhana agar mudah digunakan pada layar smartphone.

**Fitur tampilan:**
- Navigasi berada di bagian bawah layar.
- Statistik pembelajaran ditampilkan dalam dua kartu.
- Kartu melanjutkan belajar disesuaikan dengan lebar layar.
- Informasi kelas langsung ditampilkan secara vertikal.
- Tombol dibuat lebih besar agar nyaman digunakan pada layar sentuh.

### 3. Mini Design System

![Mini Design System](tutur-dasbor-mini%20desain.png)

Mini Design System merupakan panduan visual yang digunakan untuk menjaga konsistensi tampilan aplikasi Tutur.

**Komponen desain:**
- Color palette.
- Typography.
- Button.
- Input field.
- Course card.

## ✍️ Typography

Tipografi dirancang dengan ukuran yang berbeda untuk menciptakan hierarki informasi.

| Jenis | Ukuran | Penggunaan |
|---|---|---|
| Heading | 36/44 | Judul utama |
| Body | 16/24 | Teks konten |
| Caption | 13/18 | Informasi tambahan |

## 📱 Responsive Design

Desain Tutur menyesuaikan tata letak berdasarkan ukuran perangkat.

| Komponen | Desktop | Mobile |
|---|---|---|
| Navigasi | Sidebar kiri | Bottom navigation |
| Statistik | 3 kolom | 2 kolom |
| Konten utama | 2 kolom | 1 kolom |
| Tombol | Ukuran standar | Lebih lebar |
| Kelas langsung | Panel samping | Susunan vertikal |

## 🎯 Tujuan Desain

1. Membuat antarmuka pembelajaran yang sederhana dan mudah dipahami.
2. Menerapkan prinsip responsive design.
3. Menjaga konsistensi warna, tipografi, dan komponen.
4. Mempermudah pengguna memantau perkembangan belajar.
5. Memberikan pengalaman pengguna yang nyaman pada desktop dan mobile.
